# ProRL-style SASRec post-hoc evaluator

This directory contains an independently written inference adapter based on the public ProRL evaluator design. It is used after path generation and is neither a training pipeline nor a strict reproduction of the original LLM-IPP evaluator.

## Scope

- Load the pinned SASRec checkpoint strictly and run CPU inference.
- Map exact MovieLens titles to raw IDs and then to RecBole internal token IDs.
- Compute target probability using a full-vocabulary softmax.
- Compute target rank as a 1-based descending rank.
- Compute sequential item compatibility with a sigmoid of the sequence-representation/item-embedding dot product.
- Reject unknown titles in strict mode; no LLM repair or fuzzy semantic matching is performed.

The sequential sigmoid mean is reported as `SASREC_PROXY_ACCEPTABILITY`. It is a model-based proxy, not empirical CTR. SASRec is never used by SSD-PR during planning.

## Checkpoint and mapping notes

The checkpoint is loaded on CPU. Because the official file contains a RecBole `Config` pickle, `torch.load(..., weights_only=False)` is used only for the explicitly trusted pinned checkpoint. Never use this loader for an arbitrary untrusted checkpoint.

Target probability uses full-sort logits and includes the full released vocabulary. Target rank is 1-based. The adapter preserves the frozen evaluator's sequence-context behavior and does not silently truncate over-length sequences.

The released evaluator mapping passes local consistency checks, but no independent training-time token map is available. Its status is therefore `LIKELY_COMPATIBLE`, not proven identical to the mapping used during checkpoint training. This limitation prevents strict original-paper reproduction claims.

## Environment and tests

The validated environment uses Python 3.10, CPU PyTorch, RecBole, NumPy, and pandas. External MovieLens/ProRL data and the trusted checkpoint are prepared separately and are not generated by this module.

From the repository root:

```powershell
python -m unittest discover -s repro/evaluators/sasrec/tests -p "test_*.py"
```
